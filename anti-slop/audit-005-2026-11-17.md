### 1. [HIGH] Kerusakan Handler Unggah & Kompresi Foto pada Modal Edit Produk (`Bug ID Mismatch`)
- **Lokasi**: [ProductModals.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/dashboard/ProductModals.astro#L84-L89), [dashboard.client.ts](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/scripts/dashboard.client.ts#L361-L363)
- **Pelanggaran**: `my-skill` Form & Interactive Robustness / Anti-Slop `R-35` (Verify Before Deliver).
- **Detail**:
  - Pada markup `ProductModals.astro`, input file foto dan teks info kompresi didefinisikan dengan ID:
    - `id="edit-dash-camera-input"` (baris 85)
    - `id="edit-dash-compress-info"` (baris 89)
  - Namun pada `dashboard.client.ts` baris 361 & 363, pemanggilan DOM mencari ID yang berbeda:
    - `document.getElementById('edit-camera-input')`
    - `document.getElementById('edit-compress-info')`
  - Akibatnya, `editCameraInput` selalu bernilai `null`. Event listener `change` tidak pernah terpasang. Ketika pedagang mengunggah foto pengganti di modal edit produk, foto tidak dikompresi ke Canvas dan input tersembunyi `editImageBase64` tidak pernah terisi. Saat form disimpan, foto produk lama tetap tersimpan atau gagal diperbarui tanpa notifikasi yang jelas.
- **Solusi**: Samakan ID pada `ProductModals.astro` menjadi `edit-camera-input` dan `edit-compress-info`, atau sesuaikan selektor di `dashboard.client.ts`.

### 2. [HIGH] Penggunaan Bare Unicode Emoji pada Editor Notion Admin (`Pillar II: Strict Blacklist #6`)
- **Lokasi**: [ArticleEditor.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/ArticleEditor.astro#L251-L252), [ArticleEditor.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/ArticleEditor.astro#L304), [ArticleEditor.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/ArticleEditor.astro#L975-L985)
- **Pelanggaran**: `my-skill` Pillar II Strict Blacklist #6 ("Raw Unicode Emojis in UI chrome: NEVER use emojis as functional UI icons in production").
- **Detail**:
  - Baris 251–252: Menggunakan `🔗` (tautan) dan `🧹` (bersihkan format) pada bubble toolbar format teks.
  - Baris 304: Menggunakan `🖼️` pada menu pilihan slash command blok foto/gambar.
  - Baris 976, 979, 983: Menggunakan `↑`, `↓`, dan `🗑️` (`🗑️ Hapus Blok`) pada konteks menu aksi blok Notion di dalam skrip manipulasi DOM dinamis.
  - Penggunaan emoji mentah ini melanggar standard antislop: rendering emoji berbeda-beda dan seringkali pecah atau kekanak-kanakan di lintas platform (Android, iOS, Windows, Linux).
- **Solusi**: Ganti seluruh emoji fungsional dengan komponen `<AppIcon name="..." />` atau inline SVG berskala presisi (seperti icon `link`, `trash`, `image`, `arrow-up`, `arrow-down`).

### 3. [HIGH] Penggunaan Dialog Pemblokir Browser `window.confirm()` pada Admin Panduan Edukasi (`Pillar II: Respect User Intelligence`)
- **Lokasi**: [articles/index.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/pages/admin/articles/index.astro#L433), [articles/index.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/pages/admin/articles/index.astro#L469)
- **Pelanggaran**: `my-skill` Section 6 (Modal & Dialog Law) & Anti-Slop `R-39` (Interaction Affordances).
- **Detail**:
  - Penghapusan artikel edukasi (`btn.addEventListener('click', ... window.confirm('Hapus panduan...?'))`) dan video studi kasus (`window.confirm('Hapus video...?')`) masih memicu modal pop-up bawaan browser (`window.confirm`).
  - Pemanggilan dialog browser ini memblokir thread UI, tidak ramah aksesibilitas, tidak selaras dengan tema sistem desain Mamasar, dan melanggar kesepakatan bahwa seluruh konfirmasi aksi destruktif wajib melalui modal native `<dialog id="mamasar-confirm-dialog">` via `openConfirmDialog()` (`src/lib/dialog.ts`).
- **Solusi**: Migrasi pemanggilan `window.confirm` ke `openConfirmDialog({ title: 'Hapus Panduan', message: ..., confirmText: 'Hapus', cancelText: 'Batal' })`.

### 4. [HIGH] Pelanggaran Target Sentuh Minimum Mobile ($<44\text{px}$) pada Tombol Toolbar Admin (`Pillar II: Touch Ergonomics & Mobile Law`)
- **Lokasi**:
  - [articles/index.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/pages/admin/articles/index.astro#L183-L191) (Tombol mobile "Tulis" menggunakan `h-8` = 32px)
  - [AgentsPanel.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/AgentsPanel.astro#L170-L180) (Tombol mobile "Daftarkan" menggunakan `h-8` = 32px)
  - [EventsPanel.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/EventsPanel.astro#L92-L112) (Tombol mobile "Direktori" dan "Tambah" menggunakan `h-8` = 32px)
- **Pelanggaran**: `my-skill` Mobile Ergonomics & Anti-Slop `R-14` / `antislop-human` (Minimum Touch Target Size $44\times 44\text{px}$).
- **Detail**:
  - Di layar sentuh ponsel, tombol aksi utama pada toolbar admin hanya memiliki tinggi $32\text{px}$ (`h-8`), berada jauh di bawah ambang batas sentuh jari manusia ($44\text{px}$). Hal ini menyebabkan salah tekan (fat-finger error) saat admin membuka dashboard lewat smartphone.
- **Solusi**: Berikan `min-h-[44px]` atau perluas padding vertikal/horizontal (`h-10` / `h-11` pada viewport mobile atau pembungkus touch area `before:min-h-[44px]`).

### 5. [MEDIUM] Elemen Markup Zombie & Header Aksi Mati di `/admin/index.astro` (`my-skill: Dead Code Hygiene`)
- **Lokasi**: [admin/index.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/pages/admin/index.astro#L155-L174)
- **Pelanggaran**: `my-skill` Workspace Law & Anti-Slop `R-24` (Clear Navigation Hierarchy).
- **Detail**:
  - Terdapat kontainer `<div data-admin-header-group="articles" class="hidden">` yang memuat tautan "Publik" dan tombol "Tulis" (`data-open-add-article`).
  - Karena modul Panduan Edukasi telah dipindahkan ke rute tersendiri (`/admin/articles`), ketika pengguna mengklik tab "Panduan Edukasi" di sidebar, skrip langsung mengeksekusi navigasi penuh `window.location.href = '/admin/articles'`.

- **Solusi**: Hapus blok markup `data-admin-header-group="articles"` dari `src/client/pages/admin/index.astro`.

### 6. [MEDIUM] Penggunaan Tag Raw Inline SVG pada Tombol Hamburger Menu Sidebar (`Pillar II: Iconography Standard`)
- **Lokasi**: [DashboardSidebar.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/dashboard/DashboardSidebar.astro#L57-L61)
- **Pelanggaran**: `my-skill` Section 1.3 (Unified `<AppIcon>` Standard).
- **Detail**:
  - Tombol hamburger mobile `#btn-toggle-sidebar` merender raw inline `<svg>` secara langsung:
    ```html
    <svg class="w-5 h-5" fill="none" stroke="currentColor" viewBox="0 0 24 24" aria-hidden="true">
      <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M4 6h16M4 12h16M4 18h16"></path>
    </svg>
    ```
  - Standard `my-skill` mewajibkan semua ikon antarmuka menggunakan komponen terpadu `<AppIcon>` untuk menjaga konsistensi bobot goresan (*stroke width*), bounding box, dan sentralisasi aset.
- **Solusi**: Ganti inline `<svg>` dengan `<AppIcon name="menu" size="md" />`.

### 7. [MEDIUM] Kontras Teks Keterangan di Editor Notion Tidak Memenuhi Standar WCAG AA (`Pillar II: Color & Contrast Law`)
- **Lokasi**: [ArticleEditor.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/ArticleEditor.astro#L260-L314), [ArticleEditor.astro](file:///media/rasyiqi/7653717A1C07B131/mamasar/src/client/components/admin/ArticleEditor.astro#L584-L596)
- **Pelanggaran**: `my-skill` Section 2 (WCAG AA Contrast Ratio $\ge 4.5:1$) & Anti-Slop `antislop-human`.
- **Detail**:
  - Menu pop-up slash command (`#notion-slash-menu`) menggunakan `text-2xs text-slate-400` pada latar belakang putih (`#ffffff`).
  - Rasio kontras `slate-400` (`#94a3b8`) di atas latar putih hanya sebesar **2.88:1**, gagal memenuhi standar WCAG AA (minimal **4.5:1** untuk teks kecil).
  - Teks deskripsi pembantu blok (seperti "Teks bacaan biasa", "Sisipkan foto atau ilustrasi", "Pemisah horizontal antar-bagian") sulit terbaca oleh pengguna di layar beresolusi standar atau kondisi pencahayaan terang.
- **Solusi**: Ubah warna teks pembantu dari `text-slate-400` menjadi `text-slate-500` (rasio 4.6:1) atau `text-slate-600`.
